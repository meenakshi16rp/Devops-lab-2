# ENSP461 Lab 2 - Containerization & Kubernetes Orchestration

Docker, Docker Compose and Minikube workflow for the sample Flask application.

**Author:** Meenakshi | **Course:** ENSP461 - DevOps & Automation | **Lab:** 2

## Structure
- `app/` - Sample Flask application and unit tests
- `Dockerfile` - Application image (ghcr.io/meenakshi16rp/devops-lab2-app)
- `docker-compose.yml` - Multi-container setup (web + redis)
- `k8s/` - Kubernetes manifests (ConfigMap, Deployment, Service)
- `docs/` - Command logs, terminal captures and observations
