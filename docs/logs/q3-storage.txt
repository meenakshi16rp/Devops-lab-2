=== 1. Container-layer data is lost when the container is deleted ===

meenakshi@ubuntu:~$ docker run -d --name layer-demo ghcr.io/meenakshi16rp/devops-lab2-app:2.0.0
697b1688099f3d2e8b93734b976cadf809e07f8fac0f99506c63f166c9e52fbe

meenakshi@ubuntu:~$ docker exec layer-demo sh -c "echo important-data > /app/data.txt && cat /app/data.txt"
important-data

meenakshi@ubuntu:~$ docker rm -f layer-demo
layer-demo

meenakshi@ubuntu:~$ docker run -d --name layer-demo-2 ghcr.io/meenakshi16rp/devops-lab2-app:2.0.0 && docker exec layer-demo-2 cat /app/data.txt
cat: /app/data.txt: No such file or directory

=== 3. Permanent storage with a bind mount ===

meenakshi@ubuntu:~$ mkdir -p ~/bindmount-demo && echo host-file-content > ~/bindmount-demo/host.txt

meenakshi@ubuntu:~$ docker run --rm -v /home/meenakshi/bindmount-demo:/hostdata busybox cat /hostdata/host.txt
host-file-content

meenakshi@ubuntu:~$ docker run --rm -v /home/meenakshi/bindmount-demo:/hostdata busybox sh -c "echo written-by-container > /hostdata/from-container.txt"

meenakshi@ubuntu:~$ cat ~/bindmount-demo/from-container.txt   # written by the container, read on the host
written-by-container
